# Example research notes

This file stands in for the documents a real profile is drafted from (a
research log, a data inventory, a list of closed ideas). `research_profile.py
--approve` stores a hash of every file listed under `source_documents`, so if
these notes change later the profile is marked stale until you review it again.

- Instruments: NQ and ES futures; BTC perpetuals as a side project.
- Data: minute bars and tick data for NQ/ES, QQQ end-of-day options, BTC perp trades and funding.
- Closed ideas: opening-range breakout, ES/NQ pairs, time-series momentum, ES/NQ lead-lag.
